Face Recognition Prototype using SVD (Dimensionality Reduction)

1. Business Context: A foundational exploration of image processing and facial recognition algorithms, directly applicable to biometric verification systems such as Know Your Customer (KYC) pipelines.

2. Technical Approach: Implemented Singular Value Decomposition (SVD) to extract principal components (Eigenfaces) from high-dimensional image data. Successfully reduced image dimensions from 10,304 pixels to a 10-dimensional vector space while maintaining 100% classification accuracy using Euclidean distance on the AT&T face dataset.

3. Tech Stack: Python, NumPy, Matplotlib, Linear Algebra.

(Note: Technical report and presentation slides are included in this repository).
